# Development Scripts

Utility scripts for development, testing, and deployment workflows.

## Scripts

| Script | Purpose |
|--------|---------|
| `morning_start.sh` | Daily development startup routine |
| `quick_review.sh` | Quick code review checks |
| `refresh_docs.sh` | Refresh documentation |
| `run_deep_scrape.sh` | Run deep scraping pipeline |
| `run_sample_test.sh` | Run sample tests |
| `setup.sh` | Initial project setup |
| `start_server.py` | Start development server (Python) |
| `start_server.sh` | Start development server (Shell) |
| `validate_api_keys.py` | Validate API key configuration |
| `validate_migrations.sh` | Validate database migrations |
| `verify_rls_migration.sh` | Verify RLS policy migrations |

## Usage

Run from project root:

```bash
./backend/dev-scripts/start_server.sh
python backend/dev-scripts/validate_api_keys.py
```
