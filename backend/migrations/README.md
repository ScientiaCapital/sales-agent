# Database Migrations (Alembic)

This directory contains SQLAlchemy/Alembic migrations for the backend database.

## Commands

```bash
# Create a new migration
alembic revision --autogenerate -m "description"

# Apply all pending migrations
alembic upgrade head

# Rollback last migration
alembic downgrade -1

# View migration history
alembic history
```

## Migration Files

Located in `alembic/versions/`. Each migration has:
- Unique revision ID
- Upgrade function (apply changes)
- Downgrade function (rollback changes)

## Best Practices

1. Always test migrations on a branch database first
2. Keep migrations small and focused
3. Include both upgrade and downgrade logic
4. Review autogenerated migrations before applying
